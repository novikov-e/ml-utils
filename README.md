## Описание
Библиотека добавляет пользовательский аксессор `.eda_utils` к стандартным DataFrame в Pandas. Функция `build_eda_dashboard` автоматически определяет тип столбцов (числовые, категориальные, булевы, даты) и генерирует полный отчет по датасету.

## Использование
Необходимо импортировать библиотеку вместе с pandas. Аксессор зарегистрируется автоматически.
```python
import pandas as pd
import eda_utils

# Загружаем датасет
df = pd.read_csv('your_dataset.csv')

# Запускаем анализ
df.eda_utils.build_eda_dashboard(title="Анализ продаж 2026")
```

Дашборд генерирует следующие вкладки:
1. Обзор датасета - типы данных, использование памяти, информация о наличии дубликатов и пропусков.
2. Случайные строки - выборка случайных строк для визуального ознакомления.
3. Числовые признаки - статистика, гистограмма и ящик с усами.
4. Категориальные признаки - статистика, столбчатая диаграмма с топ-15 категориям.
5. Логические признаки - статистика, кольцевой график.
6. Даты - статистика, график распределения во времени.
